## Confirmed source mismatches (baseline line numbers)

1. **HFA >16 bytes incorrectly indirect** — abi_arm64.mbt:199-239 tests dark/size>16/zero before HFA detection; C abi.c:96-136 checks HFA first, permits up to four elements. `type :h = { d,d,d }; function :h $f(:h %p) { @s ret %p }` must receive/return d0-d2, not x0 pointer and x8 sret. Test three/four doubles, nested and union HFA; threshold four/five floats; zero and dark types.
2. **Cptr incomplete classification** — port:208-214 omits C ngp=1, reg[0]=*gp, cls[0]=Kl at C:124-128. argsclass's private compensation only sets class/register when GP available (port479-486); ninth indirect aggregate therefore uses Kx in stack loads/stores. Regression eight integer args followed by `{l,l,l}`.
3. **Environment ABI absent** — port argsclass504-511 records ref rather than x9/class/bit14; selcall633-635 and selpar856-858 ICE. C abi.c283-296 uses x9 and bit14. Trigger function env parameter or env call argument. types/target_arm64.mbt345-363 also misses bit14; types-util owns and reports repairing that helper.
4. **Incoming register mask absent** — port selpar omits C fn.reg=argregs at486 and fn.reg|=BIT(R8) at505. Verify argument and sret register masks before liveness/spill.
5. **Apple narrow ABI absent** — upstream apple_extsb803-852 has no port counterpart; pipeline132 calls elimsb for every target despite Apple targ.c56 using apple_extsb. ABI argsclass448 lacks Parsb/Parub/Parsh/Paruh/Argsb/etc and selpar834 uses generic Load instead of signed/unsigned narrow load. Trigger >8 GP arguments followed by sb/uh; negative sb call/return. Lead owns pipeline integration, worker will supply helper.
6. **External-symbol offset and Apple TLS selection absent** — isel_arm64.mbt162-232 omits C isel.c81-106 entire special branch. `copy extern $x+8` loses +8 when emitter uses GOT without offset. Apple `thread $x` yields descriptor rather than resolved address because no resolver call. Need per-target flag in isel; preserve calls' RCall(33), copies and offset ordering exactly.
7. **Large frame/text addressing simplified** — emitter573-662 has no C emit.c362-380 fixarg; Oaddr618-624 always `add #slot` instead of C459-477 three cases. Prologue715-729 and epilogue808-817 always add/sub immediate, omitting C >4095/>65535 register materialization. Saves/restores747-800 bypass fixarg. Trigger `alloc16 70000` escaping pointer or late spill slots. Source-exact retranscription needed including Apple IP1->V31 store scratch conflict.
8. **Apple function alignment ignored** — emitter683 comment claims force-four but only calls emitfnlnk; C560-563 assigns alignment=4. Test Apple function align output.
9. **Dead comparison mapping drift** — isel arm64_cmpop108-113 assumes wrong float order (actual C order eq/ge/gt/le/lt/ne/o/uo) and swaps ordered/unordered. Current selcmp float path never returns swap, so integer behavior is correct and erroneous float branches are unreachable through current pipeline. Preserve algorithms; share existing correct cmp helper if available, otherwise transcribe table and unit-test. emit arm64_cmpneg is unused; its float branches cannot serve semantic negation with NaNs.
10. **Dynamic alloc guard omitted** — isel336-367 duplicates util.salloc but lacks C util.c565-567 rejection when dynamic size temp has slot!=-1. Input using a stack-address temporary as allocation size is rejected upstream but accepted/rewritten here. Diagnostic parity, not ordinary allocation failure.

## Port-only binary/object interactions (no C byte-equality requirement)

All declarations read; findings below are separate from upstream text parity.

- Binary uses arm64_slot_off and common ABI/isel; all ABI failures propagate to both text and object/JIT.
- bin328-400 truncates CAddr offset Int64 to Int32 at350; >2^31/2^32 address offsets lose bits/sign. It then uses IP0 for large offsets even though target rglob reserves IP1, not IP0; live x16 can be clobbered.
- bin1037-1060 constant-to-slot uses IP1 without incrementing tmp_used, so large destination slot materialization reuses IP1 and overwrites the constant with its address. Similarly ordinary Storel from IP1 and large slot uses same scratch. C text path handles this via R18 or Apple V31.
- Binary module1566-1688 discards `_data_refs` at1629: pointer-bearing data remain data-relative offsets rather than relocated image addresses. `data $p = { l $x }` is not an absolute runtime pointer. Function-address references are not resolved against fns in pending_addrs loop1655.
- Object data relocation132-138 uses Int32 shift and add: a negative 64-bit addend adds `1 << 64` (masked shift), then right shifts wrap after32. Positive addend1 encoded across8 bytes repeats low half. Must retain Int64. Repro `data $p = { l $x+1 }`, expected 01 00 00 00 00 00 00 00.
- Object FP symbol bookkeeping: local fpN emitted adrp/add (bin345) but object is_def168-203 tests only defined function/data names, not fp_map; consequently marks fp relocations GOT_LOAD despite local ADD instruction. Needs relocation regression/link test.
- Binary atomics934-944 ignore nonzero memory offset and treat FP regs as GPR encodings; text atomic float table245-250 emits invalid ldar/stlr s/d registers. Port-only support needs explicit validation; upstream has no atomics.
- Binary vararg ELF explicit ICE1235-1236 is honest unsupported functionality, not silent parity claim. Inline assembly likewise explicit reject607-610; no C counterpart.
- bin fp_layout1492-1509 reads only b0 even for16 bytes; ARM64 isel only stashes4/8, so16-byte case is not reached through scoped pipeline; record rather than replace algorithm.
- Binary sp_adjust uses several legal add/sub chunks rather than C x16 materialization: final arithmetic agrees modulo64, but intermediate SP becomes unaligned; no intervening memory instructions, needs target execution validation rather than byte equality.

## Safe adaptations preserved

- Array-backed reverse emission preserves C curi decreasing order; helper state avoids shared globals except label/pool state reset per module.
- Block ids replacing pointers preserve successor/phi identity; Jump::full explicitly copies continuation jump rather than aliasing mutable Jump.
- Bounded register arrays replace sentinel iteration; no register-number drift observed.
- Local float pool names encoded through is_local+gasloc produce same final assembler-local symbol semantics.
- Text branch emission uses local swapped s1/s2 instead of mutating CFG, preserving emitted branch/fallthrough while avoiding hidden post-emission state changes.
- Binary/object/JIT is port-only; distinct instruction choices are not defects if shared ABI and runtime effects agree. Explicit unsupported errors are preferable to false parity.
