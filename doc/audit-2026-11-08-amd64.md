## Remaining confirmed or investigated gaps

- Apple TLS both isel.c:123-146 and emit.c:540-545 absent; extern call @plt suffix is emitted on Apple though C suppresses it. Will repair with tests.
- Missing unlikely fast-local operand rejection in division, shift, dynamic alloc (C isel.c:291-293,312-314; util.c:565-567).
- seladdr lacks upstream non-RTmp base rejection before moving base into index (C isel.c:201).
- EmitState.fsz is Int32 vs C uint64_t; framesz overflow on aggregate frame sizes.
- Float branch inversion uses cmpneg+single ctoa rather than upstream ctoa[c][n]; ordered >=/> inverted suffixes need checking because C intentionally inverts hardware flags including unordered.
- AClass.size, stk, off are signed Int32 vs uint; large aggregate sizes wrap. Need boundary evidence and bounded repair or explicit gap.
- classify flattened union FEnd scan skips runs of sentinels; empty union-member handling needs proof.
- addr.mbt addcon/runmatch replicate util algorithms; tables handwritten/copied rather than generator-owned (project rule), even though numeric table contents were manually checked equal.
- Legacy public gasemitdat in this package does not use shared gasdata full linkage/section semantics; production pipeline uses shared gasdata. Scope extension vs gas.c is documented separately.
- Windows: was absent when this report was written; now implemented in abi_win.mbt + the shared emitter and validated with `compare.py --target amd64_win` (see the round update below).

## Safe representation variations checked

- RAlloc linked Option and per-invocation AbiState replace C arena/list/globals; reverse push/read emission preserves C predecrement buffer ordering.
- AClass.type omitted but raw type sizes recovered from return or argument type index at every blit; rounded allocation and raw copy size remain separate.
- split uses stable block IDs and def_order insertion; add_blk does not append def_order, so no duplicate insertion. selvaarg transfers Jump object then replaces original with fresh Jump before mutating, preserving value-copy semantics. chpred mutates PhiArg reference objects deliberately.
- Register enums RAX..XMM15 match 1..32; NFPR=15 reserves XMM15; rsave/rclob ordering matches C without -1 sentinel because consumers iterate array lengths.
- Slot refs mask to 29 bits at construction, emitter sign_ext29 performs C rsval sign extension exactly.
- FP local labels use is_local plus gasloc at emit time rather than quoted prefixed interned text; emitted spelling equivalent for normal literals.
- debug_locs is an explicit no-C-counterpart empty extension; opt-in DWARF CFI is separate from upstream default output.

## Round update: Apple flavours and remaining Windows target

The vendored reference has \`-t amd64_apple\`, \`-t arm64_apple\` and
\`-t amd64_win\`, so Apple text can be differential-tested despite the missing
\`-G\` option. After threading the Apple flag into the amd64 selector and
implementing arm64 \`apple_extsb\`, \`compare.py -G m\` passes 7120/7120 debug
dumps and 445/445 assembly on both Apple flavours.

The only upstream target still missing is \`amd64_win\` (\`winabi.c\`):
- target registration: Target enum + CLI accept + pipeline \`run_passes_win\`
  (abi0 = elimsb, abi1 = winabi, emitfn = winabi_emitfn);
- port \`winabi.c\`'s arg/param classification (RCX/RDX/R8/R9 integers,
  XMM0-3 floats, aggregates by reference, shadow space, varargs register
  save area, stack realignment) and \`winabi_emitfn\`'s frame/prologue and
  epilogue (including the 32-byte shadow space and stack probing);
- differential gate: \`python3 compare.py --target amd64_win [--asm]\`.
Until then the CLI keeps rejecting \`amd64_win\` loudly; supported targets are
unaffected.
